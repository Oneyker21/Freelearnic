# Freelearnic

# Descripcion del proyecto
Desarrollar una aplicación móvil que facilite la contratación segura de freelancers mediante la implementación de perfiles detallados, asegurando una experiencia eficiente y confiable para clientes y profesionales.

Freelearnic es una plataforma digital diseñada exclusivamente para Nicaragua, con el objetivo de empoderar a freelancers y profesionales independientes. En un contexto donde la informalidad laboral y el limitado acceso a tecnologías digitales son desafíos significativos, esta aplicación busca facilitar el acceso a oportunidades de trabajo en línea, promoviendo el emprendimiento y proporcionando herramientas para formalizar los servicios ofrecidos.


# Instrucciones para la compilación

1. Instala Expo CLI globalmente:
```bash
npm install -g expo-cli
```

2. Instala las dependencias del proyecto:
```bash
npm install
``` 

3. Compila el proyecto:
```bash
expo prebuild
```
4. Inicia el proyecto:
```bash
npx expo start
```
5. Compila el proyecto para Android:
```bash
eas build -p android --profile preview
```
6. Descarga el archivo APK:
```bash
eas build:download -p android
```
